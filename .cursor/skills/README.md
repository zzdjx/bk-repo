# BK-REPO Skills

| Skill | 何时用 |
|-------|--------|
| `new-design` | 跨服务 / 存储语义 / 鉴权边界：先写 spec/plan |
| `new-requirement` | 新建编号需求三件套 |
| `checkpoint` | 把进展写入 progress 与需求状态 |
| `recap` | 恢复当前迭代上下文 |
| `postmortem` | 事故或里程碑复盘 |
| `generic-upload` | Generic 上传下载 / 分块 / 临时访问 |
| `storage` | blob、凭据、StorageManager |
| `auth-permission` | 认证授权、临时 token、路由鉴权 |
| `replication` | 跨集群分发、联邦、FDTP |
| `analyst-scan` | 扫描任务、执行器、质量门禁 |

工作流约定见 `.cursor/rules/workflow.mdc`。架构正文见 `docs/architecture/`。
