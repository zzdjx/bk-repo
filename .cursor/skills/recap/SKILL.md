# Recap

不要读或创建 `docs/memory/`。

1. 读 `docs/README.md`、`docs/progress.md`。
2. 对 progress 里进行中的需求，读对应 `requirements.md` / `solution.md` / `task-items.md`（不要全仓扫）。
3. 用短列表回复：当前在做、下一步、卡点、近期决策。指出文档与代码可能不一致的地方，不要假装记得聊天记录。
