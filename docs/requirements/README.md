# 需求文档索引

需求按三位数编号组织。每个需求一个目录，建议包含：

| 文件 | 用途 |
|------|------|
| `requirements.md` | 背景、目标、范围、验收标准 |
| `solution.md` | 实现方案、关键类/接口、修订记录 |
| `task-items.md` | 可勾选任务；最后一组必须含文档同步 |

头信息建议固定：编号、状态、日期、Issue/TAPD、分支、相关架构文档。

模板在 [`_template/`](_template/)。新建时用 `@new-requirement` skill，不要手抄空目录。`_template` 不占编号。

## 状态

- **规划中** — 需求分析和方案设计
- **开发中** — 正在编码
- **测试中** — 开发完成，验证中
- **已完成** — 已合入并验证
- **已取消** — 需求取消
